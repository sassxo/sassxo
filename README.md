## sassxo here 👋

I build web apps and the small tools that grow around them, mostly in TypeScript and Node, with SQLite doing more of the work than people expect. Express stays my default until something proves it shouldn't be, and I reach for React when the UI actually has state worth managing. Serverless appeals to me for the boring reason that I'd rather not pay for idle processes.
